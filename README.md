# 🐉 DnD5e-Character-Builder (Python)

Um gerador e gerenciador de personagens de RPG baseado nas regras de **Dungeons & Dragons 5ª Edição**. Este projeto está sendo desenvolvido como parte dos meus estudos práticos em Python pelo **freeCodeCamp**, evoluindo de uma aplicação de terminal para um sistema web completo com banco de dados.

## ✨ Funcionalidades Atuais

* **Criação de Personagens:** Cadastro interativo via terminal definindo nome, classe, nível inicial e atributo de Força.
* **Listagem de Fichas:** Exibição organizada de todos os personagens criados na sessão atual.
* **Validação Básica:** Tratamento de erros para evitar que entradas inválidas quebrem o menu principal.

## 🛠️ Tecnologias

* **Atual:** Python 3
* **Planejado:** SQL (PostgreSQL ou SQLite), Docker, Framework Web (Flask ou FastAPI)

## 🚀 Como rodar o projeto localmente

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
3. Acesse a pasta do projeto:
   ```bash
   cd nome-do-repositorio
   ```
4. Execute o programa:
   ```bash
   python main.py
   ```
